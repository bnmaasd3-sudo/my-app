# ملاحظات الإصدار · ٥ نوفمبر ٢٠٢٦

الرابط: https://qari-bnmaasd3-3308.vercel.app

## ما يعمل الآن
- **الشكل الجديد:** ورق وحبر ولون مميز واحد، والمكتبة مربّعات أنماط، ولكل نمط صفحة (الموسوعة والرواية والملحقات والاختبار).
- **القراءة:** حجم الخط، والوضع (تلقائي ونهاري وليلي وورقي)، وطريقة العرض، وعرض السطر، وشريط التقدّم، وحفظ الموضع، وتلميح «أضف التطبيق إلى الشاشة الرئيسية».
- **لوحة المالك:**
  - إضافة قارئ وربطه بكتاب.
  - متابعة القرّاء: بحث، وترتيب بآخر نشاط، وموضع كل قارئ في كل كتاب، وصفحة لكل قارئ.
  - تخصيص الفصول لقارئ بعينه (إخفاء فصل أو استبدال نصه).
  - إضافة كتاب أو تحديثه من ملفات ‎.md‎ ورفع صوره، وتعديل فصل بعينه.
  - نتائج اختبار تحديد النمط.
- **الحماية:** لا يُفتح فصل إلا لمن يملك الكتاب. الصفحات المحمية تحوّل غير المسجّل إلى الدخول. جهازان لكل حساب. سطر الاسم والبريد في تذييل الفصل.
- **فحص اليوم على الموقع الحي:** الصفحة الرئيسية والدخول والخصوصية والشروط تعمل بالعربية والإنجليزية. المكتبة وصفحة النمط ولوحة المالك تحوّل إلى الدخول. الصفحة غير الموجودة تعطي 404. ملف التطبيق (manifest) وأيقوناته متاحة.

## ما بقي على المالك
1. **جعل المستودع خاصًا (private)** على GitHub إن لم يكن كذلك: Settings ← General ← Danger Zone ← Change visibility.
2. **تطبيق ترحيلين على قاعدة البيانات**، كلٌّ منهما مرة واحدة في Supabase ← SQL Editor، بنسخ محتوى الملف كاملًا:
   - `supabase/migrations/20261105060000_book_active.sql`: يشغّل زر «إخفاء الكتاب من المكتبات». وبدونه يعرض الزر رسالة تطلب الترحيل.
   - `supabase/migrations/20261105070000_reader_prefs_sepia_width.sql`: يحفظ الوضع الورقي وعرض السطر في حساب القارئ. وبدونه يُحفظان على الجهاز فقط.
3. **مفتاح الخدمة في Vercel:** `SUPABASE_SERVICE_ROLE_KEY`، تحتاجه إضافة الكتب ومتابعة القرّاء.
4. **حسابات المتاجر:**
   - Google Play: حساب مطوّر، ثم أسرار `ANDROID_KEYSTORE_*` في GitHub ليخرج الإصدار الموقّع (docs/android.md).
   - App Store: حساب Apple Developer (docs/ios.md).
5. **سلة:** ربط المتجر، وضبط سر الإشعارات، وربط رمز كل منتج بكتابه من لوحة المالك (docs/salla.md).
6. **نطاق البريد:** توثيق نطاق الإرسال في Resend، وضبط `RESEND_API_KEY` و`MAIL_FROM` في Vercel، وضبط Custom SMTP في Supabase لرسائل الدخول، وضبط `OWNER_EMAIL` لصفحتي الخصوصية والشروط.
7. **قرار طلبات الحذف:** تُنفَّذ يدويًا بخطوات `docs/runbook.md` حين يطلبها صاحب البيانات.
