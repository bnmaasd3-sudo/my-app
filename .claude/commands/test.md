---
description: تشغيل الفحوص والاختبارات الآلية والبناء
---

شغّل بالترتيب، وتوقف عند أول فشل واعرض سببه:

1. `npm run lint`
2. `npm run typecheck`
3. `npm test`
4. `npm run build`
5. `npm run test:visual`: الفحص البصري لشاشة القراءة والفهرس والمكتبة (بعد البناء). صُوَره في `test-results/visual`.

ثم اعرض جدولًا: الفحص | النتيجة | عدد الاختبارات.

الاختبارات الثابتة التي يجب أن تكون موجودة وخضراء عند وجود ميزاتها (المرحلة 1 فما بعد): الدخول، فتح فصل مملوك، رفض فصل غير مملوك، سطر اسم القارئ في تذييل الفصل، والفحص البصري (لا تمرير أفقي، وعمود النص 60% من العرض على الأقل أو في أقصى عرضه). إن غاب أحدها والميزة موجودة، أبلغ بذلك. لا تعطّل اختبارًا ولا تتخطّه لتمرير الفحص.
