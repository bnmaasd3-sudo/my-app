---
description: تشغيل الفحوص والاختبارات الآلية والبناء
---

شغّل بالترتيب، وتوقف عند أول فشل واعرض سببه:

1. `npm run lint`
2. `npm run typecheck`
3. `npm test`
4. `npm run build`

ثم اعرض جدولًا: الفحص | النتيجة | عدد الاختبارات.

الاختبارات الثابتة التي يجب أن تكون موجودة وخضراء عند وجود ميزاتها (المرحلة 1 فما بعد): الدخول، فتح فصل مملوك، رفض فصل غير مملوك، العلامة المائية موجودة. إن غاب أحدها والميزة موجودة، أبلغ بذلك. لا تعطّل اختبارًا ولا تتخطّه لتمرير الفحص.
